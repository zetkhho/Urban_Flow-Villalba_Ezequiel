## Introducción:
  La localidad llamada Vaalserberg de Bélgica se encuentra en la zona fronteriza y limita con los paises de Países Bajos y Alemania. Esta localidad cuenta con un sistema de radares urbanos para la detección de infracciones por exceso de velocidad. Los registros históricos provienen de sistemas heredados, el cuál presenta errores de formato, faltante de datos generando registros inconsistentes en el nuevo sistema.
Debemos analizar y depurar los datos de viejo sistema para obtener información relevante sobre las infracciones y de está forma en el futuro poder incorporar los datos al nuevo sistema sin inconsistencias.
Descargar el dataset speeding fines https://raw.githubusercontent.com/HAD141/datasets/refs/heads/main/TrabajosPracticos/urban_flow/speeding_fines.csv
El dataset contiene información histórica de multas por exceso de velocidad y presenta errores que deberán ser tratados para evitar inconsistencias.
El dataset analizado contiene informacion sobre infracciones. Se utilizo .head() para revisar el dataset y dar un pantallazo de las categorias. Tiene valores como la multa_id, velocidades, patente, horarios y fechas que se realizaron. Gracias al analisis del dataset, se observo que hay patrones de reincidencia, y horarios en donde la cantidad de multas es mayor.
Tambien se observo que hay varios problemas de calidad de los datos, por lo que se necesito normalizar fechas, horas, patentes y ubicaciones. tmb se necesitro tratar valores nulos o invalidos. se utilizo fecha 1932-01-01 y hora 00:00 para tratar esos valores, y dejo en evidencia la cantidad de valores o resgistros incorrectos, pero eso no indica que esa frecuencia corresponda a un comportamiento, sino que es resultado del procesamiento de los datos.
Una vez procesado el dataset, quedo listo para el analisis, se constato que ciertas patentes presentan mayor reincidencia, que algunas ubicacione concentran gran parte de las infracciones y que existen diferemcias importantes entre el exceso real de velocidades y el exceso considerado para las infracciones.
En conclusion el dataset es util para estudiar las multas y exceso de velocidad pero siempre teniendo en consideracion las diferentes formas de procesar los datos.
